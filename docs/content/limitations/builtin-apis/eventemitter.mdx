- **EventEmitter:** Literal event names use fixed argument tuples.
  Computed string names require a constant prefix or suffix that excludes `error`, meta events, and stream-internal events; their arguments must match the exact arity and support checked conversion.
  Unrestricted names, symbols, names that may reach internal events, and typed `listeners()`/`rawListeners()` results for names with possible computed registrations are unsupported.
  `events.once` accepts EventEmitter and stream instances with a literal event name and an optional object-literal `{ signal }`; a stream's `data` event, other options values, and EventTarget emitters are unsupported.
  `events.on` is supported as the iterated value of a `for await` loop, with the same emitters and event names and an optional object-literal `{ signal, close }`; its iterator in other positions, the watermark options, and close events given other than as string literals are unsupported.
  `captureRejections` (the constructor option and the `EventEmitter.captureRejections` default) routes the rejection of a typed promise-returning listener, registered under a literal event name, to the emitter's `[captureRejectionSymbol]` method or its `error` listeners on the next tick; a rejection reason that is not an `Error` is thrown rather than emitted.
  Reading `captureRejections` through an ES module namespace or named binding, and constructing an EventEmitter subclass with options through a class value or under a computed base class, are unsupported.
  Reading `defaultMaxListeners` through a CommonJS destructured or member binding (`const { defaultMaxListeners } = require("events")`) is unsupported.
